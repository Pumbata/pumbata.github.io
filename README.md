# pumbata.github.io

Root site for Mc Gaming Studio. It exists for two things:

- `app-ads.txt`: AdMob's authorized-seller file, which must sit at the root of the developer website listed on Google Play (`https://pumbata.github.io`).
- `index.html`: sends visitors to the studio site at https://pumbata.github.io/Mc-Gaming-Studio/
